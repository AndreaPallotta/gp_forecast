# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-08-17

### Added
- Multi-resolution app launcher icons across Android (`mipmap`), iOS (`AppIcon`), and Windows platforms.
- Windows MSIX packaging configuration and internet client network capability declarations.

### Security & CI
- Hardened GitHub Actions release workflow with concurrency controls, pinned action versions, and job timeouts.

---

## [0.1.0] - 2026-08-14

### Added
- Initial release of GP Forecast client-side Formula 1 race win probability predictor.
- On-device Bayesian prediction model and offline-first SQLite cache.
- Adaptive glassmorphic UI with dynamic weather adjustments and live overtaking simulator.
